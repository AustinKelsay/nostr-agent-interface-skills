# Security Policy

## Scope

This repository contains public skill-package content for the `skills` ecosystem. It does not contain the full `nostr-agent-interface` product source code or release binaries.

The current skill package is markdown-only and does not bundle executable helper scripts, but skill content can still influence agent behavior and command selection. Treat it like code: review changes before installing and pin to known revisions if you need strict change control.

## Supported Version

Security fixes are applied on the latest `main` branch state of this repository.

## Reporting A Vulnerability

Please do not open public GitHub issues for security-sensitive reports.

Report security concerns by email:

- `austinkelsay@protonmail.com`

Include:

1. a short description of the issue
2. affected file paths or install flow
3. reproduction steps
4. any suggested mitigation

If the concern belongs to the upstream product rather than this public skills package, please note that in the report so it can be routed correctly.
